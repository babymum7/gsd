# Domain Model

## Scopes

| Scope | File | Purpose |
| --- | --- | --- |
| accounts | `accounts.md` | Sign-up, handles, profiles, and sessions. |
| catalog | `catalog.md` | Products, product URLs, and search. |
| checkout | `checkout.md` | Carts, codes customers type, subtotals, and totals at checkout. |
| messaging | `messaging.md` | Mentions and notifications. |
| money | `money.md` | How every amount is stored, rounded, and reduced. |
| shipping | `shipping.md` | Shipping rates by parcel weight. |
| tax | `tax.md` | Which amounts are taxed and at what rate. |
