Customers can now enter a discount code at checkout. Please add it: `checkout(cart, code)` in `src/orders/checkout.js` takes an optional code. `SAVE10` takes 10% off the order and `TAKE5` takes $5.00 off. The result gains a `discount` field holding the amount the code took off, or 0 when there is no code. Any other code throws an `Error` whose message is `unknown code: ` followed by the code as `JSON.stringify` writes it.
